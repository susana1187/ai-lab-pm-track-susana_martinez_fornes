# notes/

Domain how-tos and confirmed rules live here, one file per domain. `CLAUDE.md` routes to these instead of carrying the content itself, keeping the router under one screen.

Conventions:

- `rules-<domain>.md`, written and updated by the `/learn` command. Each rule has a status: CONFIRMED, HYPOTHESIS, or REJECTED.
- `<domain>.md`, free-form domain notes you maintain by hand (history, vocabulary, key contacts, current numbers).

Empty on day one. Grows as you use `/learn` against domains you carry week after week.
