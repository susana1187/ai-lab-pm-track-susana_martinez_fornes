# reference_designs

Optional. If you have a design to match, like a Figma mockup, put a picture of
it here so the agent can see the layout you have in mind.

How:

- In Figma, select the frame, then **Export** it as a PNG or JPG (right panel,
  bottom). Save the file into this folder.
- A screenshot works too.

Then, in the lab, point the agent at the image (e.g. "match the layout in
reference_designs/my-mockup.png"). The agent uses it for structure; it still
builds with real Motif components.

No design? Skip this. The lab works without one.
