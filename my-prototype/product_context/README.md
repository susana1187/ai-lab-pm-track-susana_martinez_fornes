# product_context

Put what the agent should know about your product here. Before it builds, the
agent reads this folder.

Drop in:

- Your **PRFAQ** from Session 1 (the short product-framing doc you wrote). If you
  don't remember what a PRFAQ is, the lab explains it; for now, just any short
  doc describing the thing you want a screen for.
- A filled-in copy of **`brief-template.md`** (rename it to your screen, e.g.
  `request-review.md`).
- Anything else that helps: a one-pager, notes, a list of the fields a screen
  should show.

Plain text, markdown, or pasted notes are all fine. You don't need to format
anything specially.
